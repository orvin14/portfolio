# Web Portofolio React

Website portofolio berbasis React + Vite.

## Fitur Utama

- Carousel project di halaman utama.
- Tiap card project bisa diklik untuk membuka halaman detail.
- Halaman detail project memiliki carousel screenshot.
- Routing antar halaman menggunakan React Router.

## Tech Stack

- React
- React Router DOM
- Vite

## Menjalankan Project

1. Install dependency:

	npm install

2. Jalankan mode development:

	npm run dev

3. Build production:

	npm run build

## Catatan Aset

Gambar statis disimpan di folder `public/img`.
